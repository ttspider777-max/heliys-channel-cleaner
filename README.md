# Channel Cleaner

Бот-чистильщик канала от накрученных/пустых подписчиков.

## Как это работает
Bot API не умеет получать список подписчиков, поэтому нужны два клиента:
- **ваш аккаунт** (админ канала с правом «Блокировка пользователей») — читает и удаляет;
- **бот** из @BotFather — интерфейс управления.

## Запуск
1. `pip install -r requirements.txt`
2. Скопируйте `.env.example` в `.env`, заполните `API_ID`/`API_HASH` (my.telegram.org), `BOT_TOKEN`, `OWNER_IDS`.
3. `python bot.py`.
4. В боте: `/login` → отсканируйте QR телефоном (Настройки → Устройства → Подключить устройство). Запасной вариант: `/login +79991234567` и код пишите с пробелами (`1 2 3 4 5`), иначе Telegram его аннулирует.
5. `/scan @your_channel` → отчёт → кнопка «Удалить» → подтверждение.

Сессия хранится в `data/` (на Amvera — в `/data`, переживает обновления). `/logout` — выйти.

## Признаки (баллы, порог по умолчанию 4)
Удалённый аккаунт / fake / scam — удаляется сразу. Нет фото +2, нет username +1,
давно не в сети +2, ссылка/реклама в имени +3. Один признак сам по себе не удаляет.

Команды: `/threshold N`, `/mode kick|ban`, `/whitelist [add|del id]`.

## Ограничения
- Telegram отдаёт список не всегда полностью (особенно у каналов >10 000) — бот предупредит.
- Определить «накрутку» точно нельзя, это эвристика: сначала смотрите отчёт и поднимайте порог, если сомневаетесь.
- Удаление идёт с паузой (1 с) и пережидает FloodWait — тысячи подписчиков займут время.
- Не храните `data/*.session` и `.env` в открытом доступе — это доступ к вашему аккаунту.
